# Stably 项目概览

## 1. 项目概述

- 项目名称：`Stably`
- 项目类型：稳定币收益信息与轻量决策辅助应用
- 当前阶段：`MVP`
- 形态：`Flutter App + Cloudflare Worker + D1`

## 2. 当前产品定位

当前项目更接近一个 `数据看板型 MVP`，而不是完整的交易、分配或提醒系统。

核心能力是：

- 聚合公开稳定币数据
- 展示相关 DeFi 收益机会
- 展示 Binance / OKX 的 CeFi 收益信息
- 提供本地分配参考、本地组合记录、本地提醒规则

## 3. 当前产品边界

- 不连接真实钱包
- 不执行交易
- 不托管资产
- 不提供投资建议
- 不做自动调仓

## 4. 当前数据口径

### 4.1 DeFi

- 数据源：`DefiLlama`
- 稳定币范围：按 `circulating USD` 排序的前 `20` 个稳定币
- 池子范围：只保留与这前 `20` 个稳定币相关的 DeFi pools

### 4.2 CeFi

- 数据源：`Binance`、`OKX`
- 当前展示字段：
  - 平台
  - 币种
  - 年化收益率
  - 产品类型
  - 期限
  - 状态

## 5. 当前页面结构

主页面：

- `Home`
- `Discover`
- `Allocation`
- `Portfolio`
- `Alerts`

次级页面：

- `Stablecoin Detail`
- `Settings`

## 6. 当前工程结构

### App

- `lib/app/`
  - 应用入口、主题、路由、全局状态

### Shared

- `lib/shared/`
  - 设计 token、通用组件、通用工具

### Features

- `lib/features/`
  - 按业务模块拆分的页面、模型、仓储和 provider

### Worker

- `worker/`
  - Cloudflare Worker 后端
  - Cron 同步
  - D1 数据存储

### Docs

- `doc/`
  - 当前产品与工程文档

## 7. 当前后端能力

当前 Worker 已实现：

- `GET /api/health`
- `GET /api/stablecoins`
- `GET /api/stablecoins/:id`
- `GET /api/stablecoin-chains`
- `GET /api/chains/:chain/stablecoins`
- `GET /api/pools`
- `GET /api/cefi-products`
- `GET /api/sync`
- `POST /api/sync`

并支持：

- DefiLlama 数据同步
- Binance / OKX CeFi 数据同步
- D1 存储
- Cron 定时任务
- 基础健康检查与同步日志

## 8. 当前前端状态

当前前端已完成的主线能力：

- 首页总览
- 收益发现
- 稳定币详情
- 本地分配参考
- 本地组合记录
- 本地提醒规则
- 设置页数据范围说明

当前页面文案和产品范围已经与实际后端口径同步。

## 9. 当前完成度判断

按当前 MVP 目标看，项目已具备：

- 可运行
- 可同步
- 可浏览
- 可比较
- 可做本地记录

但尚未升级为完整产品系统。

如果按当前 MVP 标准评估，项目已接近 `可持续演示和持续迭代` 状态。

## 10. 当前优先级最高的后续方向

从当前状态往后看，最值得继续补强的是：

1. `Allocation`
2. `Portfolio`
3. `Alerts`

其中 `Allocation` 是从数据看板型 MVP 走向“分配助手型 MVP”的关键模块。
