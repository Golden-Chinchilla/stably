# Stably 项目概览

## 一、项目定位
- 项目名称：`Stably`
- 产品类型：稳定币收益发现、分配辅助与本地组合追踪应用
- 客户端形态：`Flutter` 开发，面向 `iOS`、`Android`，当前支持 `Web` 预览
- 产品边界：
  - 不托管用户资产
  - 不连接真实钱包
  - 不直接执行交易
  - 以公开数据聚合、收益比较、分配建议、提醒与本地记录为主

## 八、稳定币信息展示原则
- App 内稳定币相关信息按两个维度组织：
  - 稳定币自身维度
  - 链维度
- 稳定币自身维度用于展示币本身的属性、价格、机制和规模。
- 链维度用于展示稳定币在不同链上的分布、集中度以及后续收益机会关联。
- 这一原则将用于稳定币详情页、收益发现页、风险画像页与智能分配页。

## 十、当前后端已实现能力
- 后端入口位于：`worker/src/index.ts`
- 当前已实现接口：
  - `GET /api/health`
  - `GET /api/stablecoins`
  - `GET /api/stablecoins/:id`
  - `GET /api/stablecoin-chains`
  - `GET /api/chains/:chain/stablecoins`
  - `GET /api/pools`
  - `GET /api/sync`
  - `POST /api/sync`
- 当前同步逻辑：
  - 从 `https://stablecoins.llama.fi/stablecoins` 拉取稳定币数据
  - 从 `https://yields.llama.fi/pools` 拉取收益池数据
  - 通过 `Cron` 或手动接口执行全量同步
  - 将数据写入 `D1`
  - 记录同步尝试/成功/失败状态与耗时
- 当前 D1 落库方式：
  - `stablecoins`
  - `stablecoin_metrics`
  - `stablecoin_chains`
  - `yield_pools`
  - `sync_state`
  - JSON 复杂字段先序列化为字符串存储，再在 API 返回层解析
  - 高频筛选字段已建立索引
