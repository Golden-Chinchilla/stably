# 第一阶段后端数据方案

## 一、目标

当前阶段只接入第一波最小必要数据，用于支持：

- 稳定币基础信息展示
- DeFi 收益池展示
- 后续收益发现页与分配页的数据基础

本阶段强调：

- 简单
- 可落地
- 低成本
- 与当前 Cloudflare 方案一致

## 二、数据来源 API

### Provider

- `DefiLlama`

### API 1：稳定币列表

- 地址：`https://stablecoins.llama.fi/stablecoins`

### 用途

- 获取稳定币列表
- 获取市值、价格、链分布等基础信息

### 当前需要字段

- `symbol`
- `name`
- `mcap`
- `price`

### API 2：收益池列表

- 地址：`https://yields.llama.fi/pools`

### 用途

- 获取 DeFi 收益池信息
- 作为收益发现页和后续分配逻辑的基础数据源

### 当前需要字段

- `project`
- `chain`
- `symbol`
- `apy`
- `tvlUsd`
- `poolMeta`

## 三、Cloudflare 使用的服务

### 当前必用

- `Workers`
  - 用于后端 API 与数据处理
- `Cron Triggers`
  - 用于定时拉取 DefiLlama 数据
- `D1`
  - 用于存储稳定币与收益池数据

### 后期可选

- `KV`
  - 用于缓存榜单、热点聚合结果等短时数据

## 四、后端依赖

### 必需

- `wrangler`
- `typescript`

### 推荐

- `drizzle-orm`
- `drizzle-kit`
- `zod`

## 五、HTTP 请求方案

### 使用

- 原生 `fetch`

### 不使用

- `axios`
