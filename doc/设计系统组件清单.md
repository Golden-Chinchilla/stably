# Stably 设计系统组件清单

## 1. 目标

本文档用于收口当前 Flutter 工程中的设计系统组件、职责边界和使用规范，避免页面继续各自拼装样式。

当前设计系统遵循：

- 风格基线：`Playful Minimalism & Quiet Luxury`
- 工程目标：`MaterialApp` 打底，业务 UI 通过共享组件统一

## 3. 当前术语口径

这套术语用于统一 `Home / Discover / Stablecoin Detail / Alerts / Settings` 的页面文案、字段标题和组件命名。

### 3.1 核心术语

- `Stablecoins`
  - 指稳定币列表、稳定币详情、稳定币筛选
- `Yield pools`
  - 指 DeFi 收益池、收益池列表、相关收益机会
- `Circulating USD`
  - 指稳定币当前流通规模展示口径
- `Chain coverage`
  - 指稳定币在多链上的覆盖与分布情况
- `Alert rules`
  - 指用户本地保存的提醒规则
- `Tracked yield pools`
  - 指当前产品正在展示和排序的池子集合

### 3.2 页面文案使用建议

- `Home`
  - 偏市场总览与重点摘要
- `Discover`
  - 偏数据发现与筛选
- `Stablecoin Detail`
  - 偏资料页与链覆盖页
- `Alerts`
  - 偏规则和监控上下文
- `Settings`
  - 偏产品范围、运行状态和设置项

## 4. 使用规范

### 4.1 不直接散写卡片样式

卡片类 UI 优先复用：

- `BaseCard`
- `AppInteractiveCard`

### 4.2 统一筛选与状态标签

- `AppFilterChip`：用于交互入口
- `StatusTag`：用于状态展示

### 4.3 统一数值展示

金额、APY、资产规模、统计指标优先使用统一数值样式组件，而不是页面里散写不同 `Text`。

### 4.4 统一状态页

- Loading：优先使用 `app_skeleton.dart` 中的骨架
- Empty：统一使用 `AppEmptyState`
- Error：统一使用 `AsyncSectionState.error`

### 4.5 统一页面刷新

页面级刷新统一走：

- `AppPageScaffold.onRefresh`

## 7. 后续收口方向

后续继续收口时，优先补：

- 输入类组件
- 选择类组件
- 反馈类组件
- 数据展示类组件
