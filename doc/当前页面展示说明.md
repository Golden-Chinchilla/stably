## 3. Home

页面代码：

- [home_page.dart](/f:/vibecoding/stably/lib/features/home/presentation/home_page.dart)

### 3.1 Market Overview

展示内容：

- 当前跟踪的重点稳定币概览
- 默认取排序后的第一个稳定币作为 featured item
- 显示其流通规模和链覆盖数

大致逻辑：

- 从 `stablecoinsProvider` 读取数据
- 在前端按流通规模排序
- 取第一项作为首页主卡片

### 3.2 Coverage Snapshot

展示内容：

- `Fiat-backed` 数量
- 当前跟踪的 `Yield pools` 数量
- 当前 tracked set 的 `Circulating USD` 汇总
- 最近同步状态

大致逻辑：

- 稳定币数量和总规模来自 `stablecoinsProvider`
- 池子数量来自 `yieldPoolsProvider`
- 最近同步时间来自 `healthProvider`
- 总规模使用当前列表做本地求和

### 3.3 CeFi Snapshot

展示内容：

- CeFi 产品数量
- 当前最高 CeFi 年化

大致逻辑：

- 数据来自 `cefiProductsProvider`
- 前端按可用状态、APR、产品类型等规则排序
- 取排序后的第一项作为 `Top CeFi APY`

### 3.4 Top Yield Pools

展示内容：

- 当前排序后的前几个 DeFi 池子

大致逻辑：

- 数据来自 `yieldPoolsProvider`
- 前端按 `APY` 优先、`TVL` 次级排序

### 3.5 Top Stablecoins

展示内容：

- 当前排序后的前几个稳定币

大致逻辑：

- 数据来自 `stablecoinsProvider`
- 前端按流通规模排序

### 3.6 Risk Notes

展示内容：

- 当前产品边界和风险提示

大致逻辑：

- 静态文案，无额外数据计算

## 5. Allocation

页面代码：

- [allocation_page.dart](/f:/vibecoding/stably/lib/features/allocation/presentation/allocation_page.dart)

### 5.1 Allocation Overview

展示内容：

- 当前输入条件下的分配概览
- 分配后预估的 blended APY

大致逻辑：

- 数据来自 `stablecoinsProvider` 和 `yieldPoolsProvider`
- 使用页面内的 `_derivePlan(...)` 做本地方案计算
- 当前是启发式分配，不是完整优化器

### 5.2 Scenario Inputs

展示内容：

- 资金输入
- 策略选择
- 最大池子数量
- 最低 TVL
- 稳定币筛选
- 链筛选

大致逻辑：

- 都在页面本地状态中维护
- 筛选条件会影响可参与分配的池子集合

### 5.3 Suggested Allocation

展示内容：

- 分配拆分结果
- 预估年化收益
- Allocation lines

大致逻辑：

- 基于 `_derivePlan(...)`
- 先筛掉不满足条件的池子
- 再按当前策略打分并生成若干行分配结果

### 5.4 Plan Notes

展示内容：

- 当前分配器的约束和说明

大致逻辑：

- 静态说明 + 当前方案结果摘要

## 7. Portfolio

页面代码：

- [portfolio_page.dart](/f:/vibecoding/stably/lib/features/portfolio/presentation/portfolio_page.dart)

状态与仓储：

- [portfolio_providers.dart](/f:/vibecoding/stably/lib/features/portfolio/presentation/providers/portfolio_providers.dart)
- [portfolio_repository.dart](/f:/vibecoding/stably/lib/features/portfolio/data/repositories/portfolio_repository.dart)

### 7.1 Portfolio Overview

展示内容：

- 总持仓规模
- Estimated annual carry
- 当前 tracked positions 数量

大致逻辑：

- 组合记录来自本地仓储
- 当前市场池子来自 `yieldPoolsProvider`
- 页面会尝试用持仓匹配当前池子，得到更新后的 APY 参考

### 7.2 Portfolio Snapshot

展示内容：

- Blended APY
- Tracked positions 数量
- Estimated annual carry
- Portfolio fields 摘要

大致逻辑：

- `_buildSummary(...)` 会做本地汇总计算
- `blendedApy` 按组合金额加权
- `estimatedAnnualCarry` 是方向性估算，不是精确结算

### 7.3 Tracked Positions

展示内容：

- 本地持仓列表
- 每条持仓的金额、币种、链、APY、备注

大致逻辑：

- 数据来自本地仓储
- 列表按金额优先、创建时间次级排序
- 每条持仓会尝试与当前市场池子做匹配

### 7.4 Portfolio Notes

展示内容：

- 本地记录说明
- 收益估算说明

大致逻辑：

- 静态说明
