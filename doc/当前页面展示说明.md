- [market_providers.dart](/f:/vibecoding/stably/lib/features/market/presentation/providers/market_providers.dart)

## 3. Home

页面代码：

- [home_page.dart](/f:/vibecoding/stably/lib/features/home/presentation/home_page.dart)

### 3.1 Market Overview

展示内容：

- 当前重点稳定币概览
- Featured stablecoin 的流通规模和链覆盖数

逻辑：

- 数据来自 `stablecoinsProvider`
- 前端按流通规模排序
- 默认取排序后的第一项做首页主卡

### 3.2 Coverage Snapshot

展示内容：

- 稳定币数量
- Yield pools 数量
- 当前 tracked set 的 Circulating USD 汇总
- 最近同步时间

逻辑：

- 稳定币和总规模来自 `stablecoinsProvider`
- 池子数量来自 `yieldPoolsProvider`
- 同步时间来自 `healthProvider`

### 3.3 CeFi Snapshot

展示内容：

- CeFi 产品数量
- 当前最高 CeFi APY

逻辑：

- 数据来自 `cefiProductsProvider`
- 前端按状态、APR、产品类型和平台优先级排序

### 3.4 Top Yield Pools

展示内容：

- 排序后的前几个 DeFi 池子

逻辑：

- 数据来自 `yieldPoolsProvider`
- 前端按 `APY` 优先、`TVL` 次级排序

### 3.5 Top Stablecoins

展示内容：

- 排序后的前几个稳定币

逻辑：

- 数据来自 `stablecoinsProvider`
- 前端按流通规模排序

### 3.6 Risk Notes

展示内容：

- 当前产品边界和风险提示

逻辑：

- 静态文案

## 5. Stablecoin Detail

页面代码：

- [stablecoin_detail_page.dart](/f:/vibecoding/stably/lib/features/stablecoins/presentation/stablecoin_detail_page.dart)

### 5.1 Market Overview

展示内容：

- 当前稳定币是否属于 tracked top 20
- 当前流通规模
- 链数量

逻辑：

- 数据来自 `stablecoinDetailProvider`

### 5.2 Core Profile

展示内容：

- Price
- Peg mechanism
- Price source
- Gecko ID

逻辑：

- 直接展示稳定币详情字段

### 5.3 Circulating USD Trend

展示内容：

- 当前、前日、前周、前月的流通规模趋势

逻辑：

- 数据来自 stablecoin detail 中的 `circulating` 和历史快照字段

### 5.4 Chain Coverage

展示内容：

- 链筛选 chip
- 当前稳定币的链分布卡片

逻辑：

- 数据来自 detail 中的 `chainData`
- 前端按链维度规模排序

### 5.5 Related Yield Pools

展示内容：

- 当前稳定币相关的池子
- 可按链进一步收窄

逻辑：

- 使用 `yieldPoolsBySymbolAndChainProvider`
- 数据按 `symbol` 和可选 `chain` 获取
- 前端按 `APY / TVL` 排序

## 6. Alerts

页面代码：

- [alerts_page.dart](/f:/vibecoding/stably/lib/features/alerts/presentation/alerts_page.dart)

状态与存储：

- [alert_rule_providers.dart](/f:/vibecoding/stably/lib/features/alerts/presentation/providers/alert_rule_providers.dart)
- [alert_rule_repository.dart](/f:/vibecoding/stably/lib/features/alerts/data/repositories/alert_rule_repository.dart)

### 6.1 Alerts Overview

展示内容：

- 启用中的规则数量
- 总规则数量

逻辑：

- 规则来自本地 alert rule 仓储
- 页面按启用状态统计

### 6.2 Alerts Snapshot

展示内容：

- Alert rules 数量
- Enabled 数量
- Tracked yield pools 数量

逻辑：

- 规则来自本地 alerts 仓储
- 市场池子来自 `yieldPoolsProvider`

### 6.3 Alert Rules

展示内容：

- 规则卡片列表
- 标题、描述、频率、状态、symbol / chain / threshold

逻辑：

- 数据来自本地 alerts 仓储
- 列表按：
  - 启用状态
  - 规则类型
  - 标题
  排序
- 表单中的 market matches 来自当前市场池子，用于预填 symbol 和 chain

### 6.4 Alert Notes

展示内容：

- 提醒功能边界说明

逻辑：

- 静态文案
